# Pet Jira

Это моковая доска для проверки работы агентов.

## Что умеет сейчас (MVP)

- Доска с колонками: К выполнению, В работе, Заблокировано, На проверке, Готово.
- Создание задачи: название, проект (Проект 1, 2, 3), описание, «назначить на себя».
- Перенос карточек между колонками перетаскиванием или через статус в карточке.
- Редактирование и удаление задачи.
- Без логина: пользователь пока один (моковый), задачи хранятся в `localStorage` браузера.

## Запуск

```
npm install
npm run dev
```

## Сборка

```
npm run build
```

## Структура

- `src/data.js`: колонки, проекты и текущий пользователь.
- `src/useTasks.js`: хранение задач (сейчас `localStorage`, позже база данных).
- `src/components/`: колонка, карточка и окно задачи.
