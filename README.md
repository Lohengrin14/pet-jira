# Pet Jira

Это моковая доска для проверки работы агентов.

## Что умеет сейчас

- Доска с колонками: К выполнению, В работе, Заблокировано, На проверке, Готово.
- Данные живут на сервере [pet-jira-server](https://github.com/Lohengrin14/pet-jira-server) (Render + Neon Postgres).
- Вход без пароля: выбираете пользователя из списка, от его роли зависят права.
  - Админ и Менеджер меняют и удаляют любые задачи.
  - Участник создаёт задачи и двигает только свои (где он автор или исполнитель).
  - Наблюдатель только смотрит.
- Создание задачи: название, проект, описание, исполнитель, приоритет.
- Перенос карточек перетаскиванием или через статус в окне задачи.
- Комментарии к задачам.
- Режим управления по кнопке-шестерёнке (только для админа): пользователи (создать, переименовать,
  сменить email и роль, удалить), проекты (создать, переименовать, сменить цвет, удалить пустой) и сводка.

Бесплатный сервер на Render засыпает без дела, поэтому первый запуск доски может занять до минуты.

## Запуск

```
npm install
npm run dev
```

По умолчанию доска ходит на сервер в Render. Чтобы работать с локальным сервером,
скопируйте `.env.example` в `.env.local` (там `VITE_API_URL=http://localhost:3000`).

## Сборка

```
npm run build
```

## Структура

- `src/api.js`: запросы к серверу и токен входа.
- `src/useBoard.js`: состояние доски: кто вошёл, проекты, задачи.
- `src/permissions.js`: правила ролей (копия серверных, только прячет кнопки).
- `src/data.js`: колонки, приоритеты, названия ролей.
- `src/components/`: экран входа, колонка, карточка, окно задачи, комментарии, админка.
